# Computer Assembly – Virtual Hardware Lab

## Overview

This project documents a virtual computer assembly exercise completed as part of my IT Support Specialist training.

The activity simulated the process of assembling a computer by requiring hardware components to be placed into their corresponding sections of a virtual computer.

The exercise focused on identifying computer components, understanding their proper placement, following the correct assembly sequence, and verifying the final configuration.

---

## Objectives

The objectives of this lab were to:

- Identify common computer hardware components
- Understand the purpose of major computer components
- Practice assembling a computer in a virtual environment
- Understand the correct placement of hardware components
- Follow the correct installation order within the CPU section
- Identify and correct incorrect component placements
- Verify the completed computer configuration

# Lab Walkthrough

## Step 1 — Review the Computer Components

The exercise provided a virtual computer environment along with different hardware components.

The goal was to identify each component and place it into the appropriate section of the computer.

Before placing the components, I reviewed the available options and considered the role and physical location of each component.


### Virtual Computer Assembly:

![Virtual computer assembly](https://i.imgur.com/eR429jC.png)

---

## Step 2 — Place the Hardware Components

I used the drag-and-drop interface to place each hardware component into its corresponding location.

The activity required careful attention to the placement areas. When positioning a component, the correct drop area was indicated by a white outline.

This helped simulate the process of physically installing components into a computer.

---

## Step 3 — Assemble the CPU Section

The CPU section required four components to be placed in the correct order.

The components needed to be arranged from **bottom to top**, representing their physical order within a computer.

This part of the activity reinforced the importance of understanding how hardware components interact and are physically assembled.

---

## Step 4 — Check the Configuration

After placing the components, I used the **Check** function to verify the configuration.

The activity provided visual feedback:

- **Green outline:** Correct placement
- **Red outline:** Incorrect placement

If a component was incorrectly positioned, I could adjust the placement and check the configuration again.

This provided an opportunity to troubleshoot and correct configuration errors.

---

## Step 5 — Verify the Completed Assembly

After correcting and verifying the component placements, the virtual computer assembly was successfully completed.

The completed exercise confirmed that the components had been categorized and positioned correctly.
